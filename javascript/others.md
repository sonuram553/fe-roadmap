### Serialization

The process whereby an object or data structure is translated into a format suitable for transfer over a network, or storage (e.g., in an array buffer or file format).

In [JavaScript](/en-US/docs/Glossary/JavaScript), for example, you can serialize an object to a [JSON](/en-US/docs/Glossary/JSON) [string](/en-US/docs/Glossary/String) by calling the [function](/en-US/docs/Glossary/Function) [`JSON.stringify()`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/JSON/stringify).

[CSS](/en-US/docs/Glossary/CSS) values are serialized by calling the function [`CSSStyleDeclaration.getPropertyValue()`](/en-US/docs/Web/API/CSSStyleDeclaration/getPropertyValue).
