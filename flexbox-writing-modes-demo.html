Key Takeaways

  • Main axis start/end depends on writing mode: LTR starts left, RTL starts right
  • Cross axis start/end depends on writing mode: Horizontal writing modes go top→bottom, vertical writing modes go left→right (or right→left in RTL)
  • justify-content values adapt: flex-start and flex-end automatically adjust to the writing mode
  • This is why we use logical properties: Instead of "left" and "right", we use "start" and "end"
  • Flexbox is writing-mode agnostic: It works with any writing mode without additional CSS changes
