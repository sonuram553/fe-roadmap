## React Functional Component Lifecycle

### Overview
Functional components don't have traditional lifecycle methods like `componentDidMount` or `componentWillUnmount`. Instead, they use **hooks** to manage state and side effects throughout their lifecycle.

### Lifecycle Phases

#### 1. **Mounting Phase**
When a functional component is first created and inserted into the DOM:

```jsx
import React, { useState, useEffect } from 'react';

function MyComponent() {
  const [count, setCount] = useState(0); // Initialize state
  
  useEffect(() => {
    // Equivalent to componentDidMount
    console.log('Component mounted');
    
    // Setup code (API calls, subscriptions, etc.)
    fetchData();
  }, []); // Empty dependency array = runs once on mount
  
  return <div>Count: {count}</div>;
}
```

#### 2. **Updating Phase**
When the component re-renders due to state or prop changes:

```jsx
function MyComponent({ userId }) {
  const [user, setUser] = useState(null);
  
  // Runs on every render
  useEffect(() => {
    console.log('Component rendered');
  });
  
  // Runs when specific dependencies change
  useEffect(() => {
    console.log('userId changed');
    fetchUser(userId);
  }, [userId]); // Runs when userId prop changes
  
  // Runs when state changes
  useEffect(() => {
    console.log('User state updated');
  }, [user]);
  
  return <div>{user?.name}</div>;
}
```

#### 3. **Unmounting Phase**
When the component is removed from the DOM:

```jsx
function MyComponent() {
  useEffect(() => {
    // Setup
    const timer = setInterval(() => {
      console.log('Timer tick');
    }, 1000);
    
    const subscription = subscribeToData();
    
    // Cleanup function (equivalent to componentWillUnmount)
    return () => {
      console.log('Component unmounting');
      clearInterval(timer);
      subscription.unsubscribe();
    };
  }, []);
  
  return <div>My Component</div>;
}
```

### Key Hooks for Lifecycle Management

#### `useState` - State Management
```jsx
const [state, setState] = useState(initialValue);
```

#### `useEffect` - Side Effects & Lifecycle
```jsx
// Mount only
useEffect(() => {}, []);

// Every render
useEffect(() => {});

// When dependencies change
useEffect(() => {}, [dep1, dep2]);

// With cleanup
useEffect(() => {
  return () => {
    // cleanup
  };
}, []);
```

#### `useLayoutEffect` - Synchronous Effects
```jsx
useLayoutEffect(() => {
  // Runs synchronously after all DOM mutations
}, []);
```

#### `useMemo` & `useCallback` - Performance Optimization
```jsx
const memoizedValue = useMemo(() => {
  return expensiveCalculation(a, b);
}, [a, b]);

const memoizedCallback = useCallback(() => {
  doSomething(a, b);
}, [a, b]);
```

### Key Differences from Class Components

| Class Component | Functional Component |
|-----------------|---------------------|
| `componentDidMount` | `useEffect(() => {}, [])` |
| `componentDidUpdate` | `useEffect(() => {}, [deps])` |
| `componentWillUnmount` | `useEffect(() => { return cleanup; }, [])` |
| `shouldComponentUpdate` | `React.memo()` or `useMemo()` |
| `this.state` | `useState()` |
| `this.setState` | `setState` from `useState` |

### Best Practices

1. **Use dependency arrays carefully** - Include all values from component scope that are used inside the effect
2. **Separate concerns** - Use multiple `useEffect` hooks for different concerns
3. **Clean up resources** - Always clean up subscriptions, timers, and event listeners
4. **Optimize with `useMemo` and `useCallback`** - Prevent unnecessary re-renders
5. **Use `React.memo`** - Wrap components to prevent re-renders when props haven't changed

Functional components with hooks provide a more intuitive and flexible way to manage component lifecycle compared to class components, making code more reusable and easier to test.
